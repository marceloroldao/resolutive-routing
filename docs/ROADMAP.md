# Roadmap

## v0.1 — deterministic baseline

- contracts, policy-first routing and explainability;
- three-node simulator;
- separate resource ledger;
- deterministic tests and baseline strategies.

## Next milestone

- scenario corpus and route-quality metric;
- signed job receipts supplied by M2A2 adapters;
- capability-history interface supplied by Memoria.ia summaries;
- failure/rerouting simulation;
- benchmark static assignment and broadcast against the resolver.

## Research directions, not v0.1 commitments

Learned route density, ECHO capability maps, multi-hop routing, distributed inference, job fragmentation, energy-aware scheduling, auctions, dynamic pricing and cross-provider exchange remain documented ideas only.
